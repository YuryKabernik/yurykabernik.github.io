# Yury Kabernik

Personal website and blog about software engineering: https://yurykabernik.github.io

## Repository Contents

- Blog posts and notes
- Profile pages
- Site source built with Jekyll and Chirpy

## Local Run

```bash
bundle install
bundle exec jekyll serve
```

The local build also publishes Markdown siblings for posts, tabs, and weeklies,
plus `llms.txt` and `llms-full.txt` indexes for agent access.

## Check the Site

```bash
bash tools/test.sh
```
